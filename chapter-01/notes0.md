# Chapter 0 — Cách học Database

## 💻 Code-OSS

Nơi viết và lưu bài tập.

Cấu trúc mỗi chapter:

```text
chapter-X/
├── notes.md
└── exercises.sql
```

* `notes.md`: ghi lại kiến thức đã học.
* `exercises.sql`: viết lời giải các bài tập.

## 🖥️ Terminal

Nơi thực hành và kiểm tra SQL bằng SQL Server `sqlcmd`.

Ví dụ:

1. Viết bài tập vào `exercises.sql`.
2. Mở SQL Server bằng `mssql`.
3. Thực hành câu lệnh SQL trong terminal.
4. Kiểm tra kết quả.
5. Đối chiếu với bài đã lưu trong `exercises.sql`.
